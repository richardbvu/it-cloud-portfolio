This repository serves as a central portfolio for hands-on IT support and cloud-support projects focused on Active Directory Domain Services (AD DS), Microsoft Entra ID identity and access management, Microsoft 365 administration, Microsoft Intune endpoint management, Conditional Access, and troubleshooting across Microsoft-based on-prem, hybrid, and cloud-managed environments.

- Documented hybrid identity behavior in a way that supports interview explanations around AD, Entra, synchronization, and source of authority

## Project Approach
All projects follow a consistent evidence-first structure:

- Build Evidence: confirms the environment, configuration, or workflow works as intended  
- Troubleshooting Evidence: captures symptoms, investigation steps, root cause, fix, and validation  
- Runbooks: documents repeatable procedures for common administration and support workflows  
- Ticket Pack: turns troubleshooting scenarios into polished support-style case writeups  
- PowerShell: includes useful commands, validation checks, and saved output where relevant  
- Resume/Interview: converts project work into skills summaries, resume bullets, and interview-ready stories  

This structure is used across Active Directory, Microsoft 365, Microsoft Intune, and Microsoft Entra projects so each lab produces clear proof of hands-on configuration, validation, troubleshooting, and documentation ability.
